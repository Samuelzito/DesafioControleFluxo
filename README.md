# 🔁 Desafio Controle de Fluxo em Java

Este repositório contém um desafio prático de controle de fluxo em Java. O objetivo do exercício é implementar um contador com regras específicas, reforçando o uso de estruturas de decisão (`if`, `else`) e laços de repetição (`for`, `while`).

---

## 🎯 Objetivo

Criar um programa que recebe dois valores inteiros como parâmetros e imprime uma contagem crescente entre eles.  
Caso o segundo número seja menor que o primeiro, o programa deve lançar uma exceção informando a condição inválida.

---

## 🛠️ Tecnologias utilizadas

- Java  
- IntelliJ IDEA (ou qualquer IDE Java)  

---

## 🧠 Conceitos aplicados

- Estruturas de decisão (`if/else`)  
- Laços de repetição (`for`)  
- Leitura de parâmetros  
- Lançamento de exceções  
- Boas práticas na escrita de métodos
